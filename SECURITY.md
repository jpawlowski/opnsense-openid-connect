# Security policy

This project is pre-release. Report suspected vulnerabilities privately to the
maintainer address listed in the package manifest or through a private security
advisory on the source repository. Do not open a public issue before a fix is
available.

Include the affected commit/package version, OPNsense version, provider type,
reproduction steps and the random browser error reference. Redact client
secrets, authorization codes, cookies, ID/access/refresh tokens, complete JWTs,
personal claim values and private network details not needed to reproduce.

There is currently no promised response SLA and no published release signing
key. Security fixes will state affected versions and upgrade/removal guidance in
their release notes.
